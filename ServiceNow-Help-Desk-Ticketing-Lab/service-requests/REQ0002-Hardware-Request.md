## Fulfillment Workflow

This request demonstrated the multi-stage approval process unique to hardware requests:

1. **Manager Approval** — Completed (2 days)
2. **Dept. Head Approval** — In Progress (2 days)
3. **Order Fulfillment** — Pending (4 days)
4. **Deployment** — Pending (1 day)
5. **Completed**

This workflow demonstrates how hardware procurement requires additional governance compared to standard software installations.
