## Short Description

User locked out - cannot log in to Windows account

## Description

John Carter from Finance called the help desk reporting he is unable to log in to his Windows workstation. Account appears to be locked after multiple failed attempts. User needs account unlocked and temporary password issued.

---

## Work Notes

Received call from John Carter, Finance department. User reports being locked out of Windows account after multiple failed login attempts. Verified user identity. Unlocked account in Active Directory and issued temporary password. Advised user to reset password on next login. Ticket resolved - no further action required.

---

## Resolution

Account unlocked in Active Directory. Temporary password issued to user. User confirmed successful login. Advised user to update password immediately per security policy.
