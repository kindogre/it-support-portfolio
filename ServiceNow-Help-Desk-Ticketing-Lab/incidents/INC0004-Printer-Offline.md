## Short Description

Shared office printer offline - Marketing department unable to print

## Description

Maria Santos reports the shared HP printer on Floor 2 is showing offline status. Multiple Marketing department users affected. Printer was working yesterday. No error lights visible on device. Users have tried turning it off and on with no result.

---

## Work Notes

Received email from Maria Santos, Marketing. Shared printer showing offline to all department users. Remotely checked print spooler service - found it was stuck. Restarted print spooler service on print server. Printer still offline. Dispatched to Floor 2. Found printer USB connection loose. Reseated cable. Cleared print queue. Printed test page successfully. Confirmed with Maria Santos - all users can print. Ticket resolved.

---

## Resolution

Print spooler restarted and loose USB cable reseated on shared HP printer Floor 2. Test page confirmed successful. All Marketing department users restored to full print access.
